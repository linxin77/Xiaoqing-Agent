# Xiaoqing Agent · 小晴 v0.5.0 Beta

[简体中文](README.md) | [English](README.en.md)

**让角色在你没有说话时，也能决定接下来做什么。**

为 SillyTavern 单角色聊天加入人格驱动的自主交流与场景行动。角色可以继续说话、做事、等待或结束；决定来自角色卡与当前上下文，程序负责时钟、权限、额度和执行。

例如，你在面包店里迟迟没有回应，店员可以继续贴标签、整理货架，再抬头问你是否还需要什么。场景模式会把这些可见动作写进聊天，让人物与场景自然延续；纯聊天模式则专注于主动接话与等待。

**MIT 开源。当前适合作为公开测试版发布。** 功能与发送权限默认关闭；启用后的模型判断可能收费。需要 SillyTavern 1.19.0 或更新版本所提供的接口；独立夹具验证基线为 1.19.0，不宣称已在所有新旧版本或扩展组合中实测。

## v0.5.0 改进

- **统一世界时间**：提供给模型的当前时间、上条用户时间与有效沉默保持一致。历史真实时间戳不再混入模型上下文，原聊天的时间与去重标记不改写。
- **自然等待**：连续空 WAIT 逐步延长检查间隔，并尊重模型的较长等待建议。快慢节奏、延长倍率、最大间隔全部可调；可关闭以恢复固定快测。
- **请求额度**：默认每轮最多30次自主判断，包含失败尝试；可调1–1000。快慢阶段、同源标签页及刷新共用额度。正常短期接话另受最多三次请求及失败重试限制。
- **给构思留空间**：输入框有草稿时不发起自主模型调用，也不提交草稿。强化对“正在构思、先别打断”的提示，聊天输入区保留明显的暂停时间按钮。
- **公开发布准备**：安装、贡献、安全、来源与已知限制说明；自动检查、可选浏览器验证和问题模板。

## 安装与更新

发布成 GitHub 仓库后，可在酒馆“扩展 → 安装扩展”中粘贴**本仓库的 Git URL**。本地 ZIP 不能填进 URL 输入框。

仓库根目录应直接包含 `manifest.json`、`index.js`、`README.md` 等文件。网页上传时，请上传插件文件夹里面的内容，避免把外层解压目录也一起上传。

复制安装：

1. 解压 `Xiaoqing-Agent-v0.5.0.zip`，得到 `Xiaoqing-Agent` 文件夹。
2. 放到 `SillyTavern/public/scripts/extensions/third-party/Xiaoqing-Agent/`，或当前用户的 `data/<用户目录>/extensions/Xiaoqing-Agent/`。
3. 最终插件目录应直接包含 `manifest.json`、`index.js`、`modules/` 等文件，不要套两层。
4. 刷新酒馆页面（更新时可按 Ctrl+F5），确认面板显示 **v0.5.0 Beta**。
5. 连接模型、启用小晴，按需允许主动对白。选择纯聊天或场景模式，发送一条新消息开始。

更新前建议保留旧插件文件夹。已取消或结束的任务不会因刷新、提高额度或切换模式而复活；旧设置中的输出上限会保留。

## 使用方式

- **纯聊天**：适合网络聊天，模型可主动联系，也可继续等或结束。
- **场景角色扮演**：有新的可见动作才写旁白，可与对白合成一个气泡。旁白供玩家阅读，不等于玩家扮演的角色必然知情。模式按聊天保存。
- **连续消息缓冲**：默认等5秒，连续发送或继续输入会重新计时；模型可再等待，不机械地对每条短消息单独回答。
- **时间暂停**：构思时点击“暂停时间”。小晴驱动的自主行为、场景推进和插件接话冻结；继续后从剩余时间运行。同源标签页同步。它不控制其他扩展或酒馆时间宏。

模型显式返回的角色状态摘要是角色模拟文字，不是隐藏推理或真实意识的证据。未来意图不等于已经发生的剧情事实。

## 快慢阶段与自然等待

默认先以10秒开始快速互动。快速 END 或快阶段时限到达后，等待有效沉默达到默认5分钟门槛，再进入慢阶段。门槛、时限、间隔与冷却都可调。一次沉默最多经历一段快阶段与一段慢阶段，不并行循环。

END 表示当前阶段可结束；快 END 后仍可进入慢阶段。STOP 用于用户明确要求停止主动联系，结束两个阶段。手动取消也结束两个阶段。用户新消息使旧结果失效并开始新一轮。

自然等待默认开启：快速阶段将模型建议的一分钟换算成一秒，至少为快速最短间隔，最多为可调的快速 WAIT 上限；连续安静 WAIT 会按可调倍率延长。慢阶段使用真实有效分钟及可调上限。有可见输出、换阶段或新消息后重置连续空等计数。

快速参考时间只是测试换算，不代表角色或玩家已经在场景中等了那么久。用户约定的“先安静十分钟”等等待承诺应按有效世界时间判断。提示词无法保证模型每次都理解正确，需要完全静止时使用时间暂停。

| 设置 | 默认 | 范围 |
|---|---:|---:|
| 快阶段最短间隔 | 10秒 | 1–3600秒 |
| 快速 WAIT 最长间隔 | 60秒 | 1–3600秒 |
| 慢速 WAIT 最长间隔 | 60分钟 | 1–1440分钟 |
| 连续空等延长倍率 | 2 | 1–4 |
| 慢阶段启动门槛 | 5分钟 | 1–1440分钟 |
| 快阶段最长运行 | 5分钟 | 1–60分钟 |
| 整轮最长等待 | 180分钟 | 1–10080分钟 |
| 自主可见输出上限 | 5条 | 1–100条 |
| 自主判断请求上限 | 30次 | 1–1000次 |

最大 WAIT 间隔不会低于对应最短间隔。整轮截止、快阶段截止、取消与暂停始终优先。可关闭两阶段，单独选择快速测试或分钟模式。

## 计数、费用与权限

每个实际自主气泡计一条：纯旁白计一条，动作与对白同气泡也只计一条。空 WAIT 不占输出额度。快慢阶段共享总输出上限，模型无需用完额度。

普通酒馆回复与短期接话模块的回复不占自主输出额度。**短期缓冲已经结束后，主模块补发的首次确认也属于自主输出，仍占额度**；这是当前明确的计数口径。

自主请求在调用前保守预留，失败也计数；存储异常或结果作废后不退还，避免重复调用。达到输出上限或自主请求上限均结束整轮，不补发慢阶段。正常接话最多三次请求，失败最多重试一次，两种限制同时生效，不与自主判断共享额度。

选择场景模式即允许动作旁白；主动对白需要单独开启发送权限。免打扰期间不判断、不输出；页面关闭后不运行，浏览器后台节流可能使检查延后。修改上限不保证模型必定发送消息。

## 模型与格式

复用当前模型连接，不保存 API 密钥，不依赖某个固定供应商。已确认的 OpenRouter / `deepseek/deepseek-v4.1-flash` 组合使用 JSON Schema；其他组合不强行启用 Schema，仍严格检查返回的 JSON。

格式失败、截断、鉴权、限流等错误会显示类别并按有限次数处理。不会补全残缺 JSON 后强行发送，也不会把错误文字写成角色消息。实际生成时间由供应商决定，检查间隔不等于网络响应时间。

## 数据与安全

角色卡、最近消息和显式状态摘要会发送给当前模型提供方。插件状态保存在当前聊天的独立元数据中；浏览器存储保存去重、暂停和联系间隔标记。没有独立遥测服务，不读取密钥文件。详见 [SECURITY.md](SECURITY.md)。

模型文字不会作为 slash command 执行，也不会作为设置 HTML 注入。删除心理历程不会删除聊天里已公开显示的动作或对白，也不会退还当前轮次的运行额度。

运行逻辑与语法检查不需要安装依赖：

```sh
node scripts/check.mjs
node --test tests/*.test.js
```

可选浏览器验证与开发说明见 [CONTRIBUTING.md](CONTRIBUTING.md)，结果与范围见 [docs/TEST_RESULTS.md](docs/TEST_RESULTS.md)。GitHub Actions 配置已提供，远程检查是否通过应以仓库 Actions 页的实际运行结果为准；本地检查不代表远程 CI 已运行。

当前不支持离线后台服务、系统推送、群聊或无限长期记忆。使用最近聊天与已有决策不等于拥有完整世界书触发器，也不能保证上百轮剧情始终一致。其他扩展的消息编辑、正则、生成钩子与不同模型组合需要另外测试。

公开版本采用 Beta 定位。固定输出测试证明调度与提交行为；人物是否自然、是否打扰，需要真实模型样本和使用者反馈，不能由测试数量替代。
