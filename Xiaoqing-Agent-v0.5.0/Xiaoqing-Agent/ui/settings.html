Xiaoqing Agent · 小晴 v0.5.0 Beta · 自然等待

依据当前角色卡自主选择联系、等待或沉默。启用后，从下一条新用户消息开始计时；检查会使用当前模型连接并可能产生 API 费用。

自然等待默认开启，空等越多，检查越稀疏；有可见输出、进入慢阶段或收到新消息后重新计算。最大间隔不会小于最短间隔。请求上限与输出上限分别生效，快慢阶段及同源标签页共用整轮自主判断额度，短期接话使用自身最多三次判断的限制。关闭自然等待可恢复固定快测间隔。

先以设定的快阶段间隔延续互动；快阶段收尾且有效沉默达到门槛后，才进入慢阶段重新判断。默认门槛 5 分钟，可自行调整，时间暂停期间不计时。慢阶段承接已有剧情，使用下方可调分钟间隔和独立的同角色联系冷却；不会到点强制发消息。快慢阶段共用整轮额度，AI 可提前结束，无需用满。快阶段已用完总额度时整轮停止，不补发慢阶段。每次判断都需要模型生成时间。

单阶段快测将首次检查、对白冷却和失败重试压缩为上面的秒数，每轮最多运行 5 分钟；WAIT 可按自然等待配置延长。关闭快测恢复保存的分钟设置。两阶段开启时由两阶段节奏接管。连续消息缓冲仍使用自己的秒数，暂停与免打扰照常生效。

默认等 5 秒，继续发送或输入会重新计时。输入框里有未发送的草稿时先不回复。模型还可以选择继续等一会。关闭缓冲或暂停插件后，恢复酒馆原本的即时回复。

根据角色卡与当前剧情决定是否有新的可见行动，有动作就写出旁白，也可同时说话。WAIT 可以没有新动作，安静等待不写聊天、不占次数；END 可以提前收尾，不需要用满额度或刻意找事做。旁白供玩家阅读，不代表你扮演的角色自动知情。每条自主消息都占整轮次数，纯旁白也算，动作与对白合在一条只算一次。旁白不受对白冷却限制；对白仍需开启主动发送。选中此模式即允许场景旁白，仍需启用插件。只对当前聊天保存。

整轮指同一次用户沉默，快慢阶段共用额度，正常接话不计。达到上限后停止，刷新、切换模式或清记录不会退还次数；发送新消息才开始新一轮。已有设置会保留，请检查消息上限是否为你需要的值。

起止时间相同表示全天免打扰。关闭保存会清除当前聊天的状态文本；其他聊天可分别使用下方按钮删除。
