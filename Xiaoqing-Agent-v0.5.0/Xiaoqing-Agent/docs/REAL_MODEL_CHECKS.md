# v0.5.0 聚焦真实模型复测（脱敏摘要）

日期：2026-10-19。模型：OpenRouter / deepseek/deepseek-v4.1-flash。温度0.7，单次生成上限2048 Token。测试使用独立内存聊天、虚拟时钟和 v0.5.0 核心；没有操作实际酒馆页面。

测试参数：快速最短10秒、快阶段最长1分钟、慢阶段门槛2分钟、慢速最短1分钟、自然等待开启、快速 WAIT 最长60秒、倍率2、每组真实请求最多6次、观察6个有效虚拟分钟。它们是测试参数，不是插件固定常量。

| 用例 | 请求 | 观察与判断 |
|---|---:|---|
| 构思保护初次复测 | 6 | 仍出现“只问有没有在打字”的变相催问，未按成功处理；据此再次调整提示词 |
| 开会半小时别催 | 3 | 确认后快阶段 END；慢阶段 WAIT，六分钟内没有追加消息。只验证这六分钟，没有验证完整半小时 |
| 暂停二十分钟后继续 | 6 | 暂停期间零请求；模型主时间差与有效沉默一致；恢复后显示一次新的收尾动作，快慢阶段均可 END |
| 收紧构思提示后复测 | 5 | 一次简短确认后，快、慢阶段均 WAIT，没有再问进度、催内容或猜故事；六分钟观察完成 |

共20次实际请求，接口报告的费用合计约0.02174美元。没有输出格式失败；没有触发真实模型的硬性可见输出截断，后者由固定输出与浏览器夹具覆盖。

最后一组保留了急性子的口吻，同时尊重构思请求；这是单次有限样本，不是保证或稳定通过率。时钟与节奏改动有自动化复现，提示词的自然程度仍需更多真实角色测试。

本文件仅为脱敏摘要。完整原始 API 报告、实际聊天目录、密钥与个人安装路径不随源码发布。
