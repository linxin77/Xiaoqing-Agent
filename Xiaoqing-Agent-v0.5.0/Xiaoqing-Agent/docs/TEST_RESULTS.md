## 本轮新增覆盖

13项针对性检查验证：世界时钟在暂停、恢复和新用户消息后保持连续；缓冲与历史上下文不混入现实时间戳；自然等待的建议时间、渐进延长与上限；动作输出后的重置；草稿零请求；失败计入请求上限；跨刷新、同源标签页及快慢阶段共用请求额度。

固定三分钟、始终安静 WAIT 的复现：关闭自然等待18次请求，开启后5次；均没有强制输出。这个结果不代表所有真实模型场景都能节省同样比例。

原有205项固定节奏回归明确关闭自然等待以保留兼容基线；新增用例明确开启自然等待，另验证默认配置确实开启。没有把新功能关掉后宣称它通过测试。

使用插件生产入口、UI、事件、存储、引擎和适配器，验证普通接话、场景动作、迟到结果、双阶段、输出上限、暂停和跨页同步、停用清理。
