# 安全与隐私

插件复用酒馆当前模型连接，不需要单独填写密钥，不读取密钥文件，不内置模型账号，也没有独立遥测服务。角色卡、最近消息和显式生成的角色状态摘要会交给当前模型提供方。

状态保存在当前聊天的插件元数据中；浏览器本地存储只保存用于去重、联系间隔和暂停同步的运行标记。关闭保存状态文本或删除心理历程不会删除已经出现在聊天里的对白与旁白。

默认自主功能和主动对白权限关闭。开启后模型判断可能收费：安静 WAIT 和失败请求也可能消耗额度。整轮自主请求上限与可见输出上限独立生效；正常接话最多三次请求，失败最多重试一次，两种限制同时生效。公开源码不代表模型服务免费。

原始错误、模型隐藏推理、密钥和聊天原文不应进入调试日志。反馈问题时只提供脱敏错误类别和最短复现。若怀疑密钥已泄露，请在原模型平台撤销更换。

发现可利用的安全问题，请优先使用仓库 Security → Report a vulnerability（若维护者已启用）；否则先联系仓库维护者，不要在公开 Issue 中粘贴密钥或可直接利用的私人数据。

扩展运行于 SillyTavern 浏览器环境。请从你信任的仓库安装，不向不明来源扩展提供账号或模型权限。
